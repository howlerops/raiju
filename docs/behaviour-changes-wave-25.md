# Behaviour changes in wave 25

Wave 25 (L195 to L199) fixed the findings of the production re-audit (docs/audits/production-reaudit-2026-10-25.md). These changes can affect an existing deployment; read them before upgrading.

- **L195**: with `cluster.enabled` or `-mode broker` the gateway refuses to start when `cluster.secret` is empty, names an unset env var, or is shorter than 32 bytes (rotate short secrets before upgrading); `cluster.secret`, `discovery.advertise_address` and the push gateway, otel and alert-channel values written as `env.NAME` are now resolved (they were used literally); the helm chart needs `cluster.secret.existingSecret` when clustering is on and serves peer routes on a cluster listener (7946) by default; `server.metrics_token` puts /metrics behind a bearer token (open by default, as Bifrost).
- **L198**: passwords are bcrypt (cost 10, as Bifrost); stored salted SHA-256 passwords are rewritten in config.json at the user's next sign-in; sign-in throttling is on by default (429 with Retry-After after 5 failures per account or 20 per address within an hour; `server.sign_in_throttle`); the audit log and the throttle take X-Forwarded-For / X-Real-IP only from peers listed in `server.trusted_proxies` (set it behind an ingress or load balancer, or every client shares the proxy's address).
- **L199**: a Bun.serve worker killed by SIGKILL (the OOM killer) is respawned with a crash-loop backoff instead of stopping every worker; a build without TV_PLAIN_ALLOC refuses to start (RAIJU_ALLOW_UNSAFE_ALLOC=1 overrides with a warning); logs_store.max_disk_mb defaults to 512 (0 for no cap); a startup notice lists the changed defaults a config relies on once, recorded in `.raiju-notices.json` beside the config; state files carry a version and a newer file is left alone; the ECS module runs one task unless cluster_enabled, mounts EFS read-write with a /tmp volume, and sets the ALB idle timeout to 55 s.
- **L197**: config saves from several workers (or nodes sharing the file) are merged under a file lock; a save that collides with another worker's change to the same value answers 409 (it was silently overwritten); dashboard sessions, OIDC sign-ins in flight and agent tokens are shared by a node's workers and survive restarts and OIDC config edits, in 0600 files beside the config (`<config>.sessions.json`, `<config>.oidc-flows.json`, `<config>.agent-sessions.json`, secrets sealed, tokens hashed); async jobs are shared by a node's workers.
- **L196**: with auth enforced, an inference body over 64 KB without a valid credential is answered 401/403 before it is read, and a large /api body is refused by the gate unread (both servers now stream bodies over 64 KB to the gateway); new `server.max_buffered_body_mb` (default 48, -1 for no cap) caps the request-body bytes each process reads at once: a body that does not fit gets 503 with `retry-after: 1`, and a lone body is always admitted.
